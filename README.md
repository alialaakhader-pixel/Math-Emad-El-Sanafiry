# منصة مهندس فارس عماد للرياضيات

منصة رياضيات عربية RTL مبنية على **Next.js App Router + TypeScript + Tailwind CSS + PostgreSQL + Drizzle ORM**. تتضمن صفحة رئيسية دون بيانات مختلقة، حساب طالب ومدرس، محاضرات محمية، أكواد اشتراك، اختبارات وواجبات، معمل رياضيات، وإدارة محتوى.

> **ملاحظة تقنية صريحة:** بيئة المشروع المقدمة هي Next.js/Drizzle وليست Vite/Supabase Auth. لذلك نُفّذ نظام المصادقة وواجهات الخادم داخل Next.js، ويمكن استخدام PostgreSQL المستضاف لدى Supabase بوصفه قاعدة بيانات عبر `DATABASE_URL`، لكن **Supabase Auth/Storage/Edge Functions غير موصولة**. لم يتم ربط مستودع GitHub أو النشر على Vercel آلياً؛ اتبع خطوات النشر أدناه. لا تُعرض صورة للمدرس أو شهادات أو تقييمات أو أسعار أو أرقام غير موفّرة.

## التشغيل محلياً

1. استخدم Node.js 20+ وPostgreSQL. نفّذ `npm install`.
2. ضع `DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DB_NAME` في `.env`.
3. نفّذ `npx drizzle-kit push` لإنشاء الجداول، ثم `npm run dev`.
4. افتح `http://localhost:3000`؛ ستكون الصفوف والمحاضرات فارغة حتى يضيف المدرس محتوى حقيقياً.

## إعداد حساب المدرس (مرة واحدة فقط)

أضف إلى متغيرات **الخادم فقط** `TEACHER_SETUP_SECRET` بقيمة عشوائية طولها 20 حرفاً على الأقل، ثم أرسل طلباً واحداً. مثال (استبدل القيم عبر متغيرات بيئة؛ لا تحفظ كلمة المرور في المستودع):

```bash
curl -X POST http://localhost:3000/api/auth/bootstrap \
  -H 'Content-Type: application/json' \
  -H "x-setup-secret: $TEACHER_SETUP_SECRET" \
  -d '{"name":"مهندس فارس عماد","email":"TEACHER_EMAIL","password":"STRONG_PASSWORD_12_CHARS_OR_MORE"}'
```

بعد نجاح الطلب **احذف `TEACHER_SETUP_SECRET` من البيئة وأعد تشغيل الخادم**. يُرفض إنشاء مدرس ثانٍ عبر هذا المسار. سجّل دخول المدرس من `/auth?mode=login` ثم أضف صفوفاً ومحتوى من `/admin`. الاسم المعروض في الواجهة هو اسم المنصة الذي قدمه صاحب الطلب؛ النبذة وروابط التواصل يضيفها المدرس بنفسه.

## إعداد الخدمات الاختيارية

| المتغير | الوظيفة |
| --- | --- |
| `APP_URL` | أصل الموقع الموثوق (مثل `https://example.com`) لروابط OAuth والاستعادة. |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | تسجيل Google OAuth مع PKCE؛ أضف `APP_URL/api/auth/google-callback` ضمن Authorized redirect URIs في Google Cloud. لا يظهر زر Google بدون الإعداد. |
| `RESEND_API_KEY`, `RESEND_FROM_EMAIL` | إرسال رابط استعادة كلمة المرور عبر Resend من نطاق مُوثّق. بدونها تظهر رسالة عدم توفر الخدمة. |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | مساعد رياضيات عربي عبر OpenAI Responses API. النموذج الافتراضي `gpt-4.1-mini`. لا يظهر المساعد كخدمة متصلة بدون المفتاح. |
| `DATABASE_URL` | قاعدة PostgreSQL؛ يجب أن تكون متاحة للخادم لا للمتصفح. |

لا تستخدم بادئة `NEXT_PUBLIC_` للأسرار. لا تُخزن المفاتيح في الكود أو الواجهة. إعداد مزود Google/Resend/OpenAI قد يتطلب حساباً أو رسوماً خارجية.

## وظائف المنصة

- **الطالب:** إنشاء حساب، دخول وخروج، Google عند تهيئته، استعادة كلمة المرور عند تهيئة البريد، اختيار الصف، تعديل الملف، تغيير كلمة المرور، عرض الاشتراك وتفعيله، متابعة المحاضرات ومذكراتها المصرح بها، حفظ التقدم، أداء الاختبارات والواجبات ورفع صورة/PDF كإجابة، عرض الدرجات الفعلية، الإشعارات، وعرض/إلغاء الجلسات الأخرى.
- **المدرس:** إدارة الصفوف والترم والوحدات والمحاضرات وملفاتها، الامتحانات والأسئلة، التصحيح اليدوي، الطلاب، أكواد التفعيل الأحادية، التفعيل اليدوي بالمعرّف، الإعلانات، الإشعارات، نبذة المدرس والروابط، تغيير كلمة المرور، وسجل العمليات.
- **المعمل:** رسم دوال ثنائية الأبعاد مع تكبير وتحريك ونقاط تقاطع، محرر LaTeX، سبورة مع أدوات وتراجع/إعادة وتنزيل PNG، آلة علمية، هندسة ومساحات/حجوم ومتجهات، مجسمات ثلاثية الأبعاد وسطح `z = sin(x) cos(y)`، وحفظ أعمال الطلاب.
- **الصفحة العامة:** الصفوف والمحاضرات والإعلانات تأتي من قاعدة البيانات فقط؛ الأقسام غير المعبأة تظهر كحالات فارغة صريحة. لا توجد بيانات Seed في الإنتاج.

## أمان الوصول

- كلمات المرور مجزأة بـ `scrypt` مع Salt عشوائي؛ الجلسات وأكواد التفعيل وروابط الاستعادة تُخزن كبصمات SHA-256، والجلسة في Cookie `HttpOnly; SameSite=Lax; Secure` في الإنتاج.
- التحقق من دور المدرس واشتراك الطالب يتم **داخل الخادم** عند كل طلب للمحتوى/الملف/الاختبار. لا تَعرِض واجهة الاختبار الإجابات الصحيحة قبل إتاحة مراجعتها.
- تطبيق محاولات محدودة للدخول واستعادة كلمة المرور وتفعيل الأكواد والمساعد؛ الأكواد تُحدّث وتُستخدم ذرياً داخل معاملة قاعدة البيانات، ويظهر نص الكود للمدرس مرة واحدة بعد إنشائه فقط.
- الملف المخزن في قاعدة البيانات لا يُحمّل إلا عبر `/api/files/[id]` بعد فحص الصلاحية. حجم الملف الواحد **4MB** (PDF/MP4/WebM للمحاضرات؛ PDF/PNG/JPEG لإجابة الواجب).
- `database/rls.sql` يحتوي سياسات RLS دفاعية **اختيارية** لدور PostgreSQL مخصص غير مالك للجداول. لا تُفعّلها دون ربط جميع معاملات ذلك الدور بـ `SET LOCAL app.session_hash` وإبقاء عمليات الخادم الحساسة بدور خدمة موثوق. التشغيل الافتراضي يعتمد على API خادمي خاص وفحوص صلاحية صريحة؛ **RLS غير مفعّل افتراضياً**. هذا ليس بديلاً عن Supabase RLS/Auth إن قررت نقل الهوية إليه لاحقاً.

### حدود مهمة قبل النشر التجاري

- ملفات الفيديو الكبيرة لا تناسب تخزين Base64 داخل PostgreSQL. استخدم مزود بث/تخزين خاصاً مع روابط موقعة قصيرة العمر وقيود تشغيل مناسبة. الروابط الخارجية لـ YouTube/Vimeo لا تمنع مشاركة الرابط ولا تقدم DRM؛ واجهة المنصة تحمي **الوصول للصفحة** فقط. لا تدّعِ حماية الفيديو الخارجي بالكامل.
- الجلسات قابلة للإلغاء عن بُعد، لكن **لا يوجد حد عددي ثابت للأجهزة**؛ تظهر هذه السياسة بوضوح داخل لوحة الطالب.
- محاولة الاختبار تُقيَّد بوقت ومحاولات من الخادم. الأسئلة المقالية تنتظر تصحيح المدرس. لا تُعدّل الأسئلة أثناء اختبار جارٍ إلا بعد مراعاة أثر ذلك على التصحيح.
- لا يُرسل المساعد صوراً حالياً؛ الخدمة النصية فقط عند إعداد المفتاح. يجب مراجعة إجاباته تعليمياً.
- استعادة البريد وGoogle والمساعد تحتاج مفاتيح فعلية ولا يمكن اختبار مقدميها دون تهيئتها.

## اختبار يدوي سريع

1. أضف حساب مدرس عبر bootstrap ثم سجّل الدخول. أنشئ صفاً وترماً ووحدة ومحاضرة منشورة واختباراً بأسئلة، وأنشئ كوداً وانسخه فوراً.
2. أنشئ حساب طالب ببريد مختلف. تحقق أن `/admin` يعيد توجيهه وأن `/api/admin` يرد 403. اختر الصف؛ تأكد أن المحاضرة المحمية مغلقة قبل الاشتراك.
3. فعّل الكود من لوحة الطالب؛ تحقق من ظهور المحاضرة ثم جرّب إعادة استخدام الكود (يجب الرفض) وملف PDF المحمي.
4. ابدأ الاختبار، سلّم الاختيارات، وتحقق من نتيجتك؛ جرّب إجابة مقالية وتصحيحها من لوحة المدرس. راجع الإجابات فقط إذا فُعّل خيار المراجعة.
5. احفظ عملاً من المعمل، جرّب الوضع الليلي/النهاري والجوال، ثم ألغِ جلسة من حساب الطالب.

## النشر

ارفع المستودع إلى GitHub بنفسك ثم اربطه بمشروع Vercel. اضبط `DATABASE_URL` بقاعدة PostgreSQL مستضافة تدعم الاتصال من Vercel، و`APP_URL` بنطاقك، وبقية الأسرار من إعدادات Vercel. طبّق المخطط بـ `npx drizzle-kit push` على قاعدة الإنتاج قبل استقبال الزوار، وأنشئ المدرس مرة واحدة بمفتاح مؤقت ثم احذفه. البناء: `npm run build`. لا يمكن الوصول إلى قاعدة البيانات المحلية من Vercel. لم يُنفّذ نشر أو ربط فعلي بـ GitHub/Vercel في هذه البيئة.

## الهيكل

- `src/db/schema.ts`: الجداول والعلاقات والفهارس.
- `src/lib/auth.ts`: الجلسات، كلمات المرور، حماية الاشتراكات وحدود المحاولات.
- `src/app/api/`: API المصادقة والإدارة والطلاب والملفات والمساعد ومراجعة الاختبار.
- `src/components/`: الواجهة الرئيسية ولوحات الطالب والمدرس ومشغل المحاضرات والمعمل.
- `src/app/`: الصفحات والمسارات وSEO والحالات الاستثنائية.
- `database/rls.sql`: سياسات PostgreSQL الاختيارية للتوسعة الأمنية.

## تحديثات معمل الرياضيات العربي

- تم تحسين محلل المعادلات ليدعم الأرقام العربية/الفارسية والإنجليزية، والمتغيرات س/ص/ع أو x/y/z، والضرب الضمني والأقواس والكسور ذات المقام الثابت. يحلل كثيرات الحدود حتى الدرجة الثانية بدقة، ويرفض القسمة على تعبير يحتوي على المجهول أو الأسس الأعلى من ٢ بدلاً من إعطاء نتيجة مضللة.
- تم إصلاح التفعيل اليدوي بالـ ID: يتحقق الخادم من الطالب والصف داخل معاملة واحدة، ويضيف مدة الاشتراك بعد نهاية الاشتراك النشط بدلاً من تصفير المدة المتبقية، ويعيد تاريخ الانتهاء للوحة المدرس.
- طُوّرت الآلة العلمية لتقبل الأرقام العربية والرموز الشائعة، وتبديل DEG/RAD، ودوال مثلثية وعكسية وجذور ولوغاريتمات، وذاكرة M+/M−/MR/MC، وAns وسجل آخر 12 عملية.
- أضيفت واجهة محسنة للمعمل بخلفية رياضية متحركة بصرياً وتبويبات قابلة للتمرير على الهاتف.
- الميزات التعليمية الملائمة للرياضيات من منصة الأحياء: المساعد الرياضي، دفتر أخطاء الأسئلة، تحليل نقاط الضعف، خطط المذاكرة والتنبيهات، الحصص المباشرة والسبورة، بنك الأسئلة والاختبارات والواجبات والتصحيح، ولوحات متابعة الطالب والمدرس. لا تُعتبر أي ميزة غير موجودة في الكود الحالي منفذة لمجرد ورودها في هذه القائمة؛ راجع أقسام وظائف المنصة وحدودها أعلاه قبل النشر.

## ترقية الإصدار (v2)

- **الآلة الحاسبة العائمة:** أيقونة ثابتة أسفل الشاشة في كل الصفحات تفتح آلة متطورة: علمية (DEG/RAD/GRAD، SHIFT، ذاكرة، سجل، أرقام عربية)، رسم دوال، معادلات (درجة 2 و3 وجملة معادلتين)، مصفوفات، إحصاء وانحدار، تحويل وحدات، أنظمة العد، مشتقات وتكامل.
- **الكتالوج:** من لوحة المدرس > المراحل والمنهج > "إضافة الصفوف والمواد الجاهزة" تُضاف: أولى باكالوريا، ثانية باكالوريا، ثالثة ثانوي مع المواد المغربية (كل مادة وحدة داخل ترم "المواد الدراسية"). العملية لا تكرر ولا تحذف. الملف: `src/lib/catalog.ts`.
- **المظهر:** شعار سداسي جديد، خلفية أشكال هندسية ورموز رياضية متحركة (تحترم تقليل الحركة)، واجهة اختبارات زجاجية (glassmorphism) مع شريط تقدم وتنقل بين الأسئلة ومؤقت ثابت.
- **ميزات جديدة للطالب:** تبويب "أدوات المذاكرة" (بومودورو، عدّ تنازلي للامتحان، أهداف يومية، ملاحظات) وبحث في المحاضرات.
- **إصلاحات:** إزالة اقتطاع النص (ellipsis/line-clamp) والسماح بلف النصوص الطويلة، وإصلاح أخطاء TypeScript في تفعيل الاشتراك اليدوي.
