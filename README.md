# منصة مستر عماد السنافيري للرياضيات
### Emad El Sanafyry | Mathematics Academy

منظومة تعليمية عربية متكاملة لتدريس الرياضيات: صفحة هبوط تحويلية، نظام طلاب، لوحة تحكم للمدرس،
نظام اشتراكات بأكواد تفعيل آمنة، اختبارات وواجبات، ومعمل رياضيات تفاعلي.

> الواجهة عربية بالكامل (RTL)، وكل الأرقام المعروضة تأتي من استعلامات حقيقية على قاعدة البيانات.
> لا توجد في الكود أرقام إحصائية أو تقييمات أو آراء طلاب مُختلَقة.

---

## 1. البنية التقنية

| الطبقة | التقنية |
| --- | --- |
| الواجهة | Next.js (App Router) · React · TypeScript · Tailwind CSS v4 |
| الحركة | Framer Motion (مع احترام `prefers-reduced-motion`) |
| الرسوم ثلاثية الأبعاد | three.js (مشاهد إجرائية بلا أصول خارجية) |
| المعادلات | KaTeX |
| قاعدة البيانات | PostgreSQL + Drizzle ORM |
| المصادقة | جلسات موقّعة عبر `httpOnly` cookie + تجزئة كلمات المرور بـ scrypt |
| النشر | Vercel (أو أي استضافة تشغّل Next.js) |

### هيكل المجلدات

```
src/
  app/
    page.tsx              # الصفحة الرئيسية (Holding page)
```

## 2. التشغيل محلياً

```bash
# 1) المتغيرات البيئية
cp .env.example .env      # ثم عدّل القيم

# 2) تثبيت الاعتماديات
npm install

# 3) إنشاء الجداول
npx drizzle-kit push

# 4) التشغيل
npm run dev
```

افتح `http://localhost:3000` — فحص الصحة متاح على `http://localhost:3000/api/health`.

### إنشاء حساب المدرس

لا تُنشأ حسابات المدرسين تلقائياً (لأمان المنصة). أنشئ الحساب ثم ارفع صلاحيته:

```bash
psql "$DATABASE_URL" -c "update users set role='teacher' where email='you@example.com';"
```

(للتطوير فقط يمكن استخدام أداة seed، لكن لا تُستخدم بيانات تجريبية في الإنتاج إطلاقاً.)

## 3. متغيرات البيئة

| المتغير | مطلوب | الوصف |
| --- | --- | --- |
| `DATABASE_URL` | نعم | اتصال PostgreSQL |
| `OPENAI_API_KEY` | اختياري | لتفعيل المساعد الذكي للرياضيات. بدونه يظهر المساعد بحالة صريحة «غير مفعّل» ولا يدّعي العمل. |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | اختياري | لتفعيل تسجيل الدخول عبر Google. بدونها لا يظهر زر Google (بدلالة صريحة على سبب عدم التفعيل). |

> جميع المفاتيح تُقرأ على الخادم فقط عبر `process.env`، ولا يُشحن أي مفتاح إلى المتصفح.

## 4. قاعدة البيانات

الجداول الرئيسية (`src/db/schema.ts`):

- `users` — الطلاب والمدرس، مع حماية من التخمين (`code_attempts`, `locked_until`).
- `sessions` — الجلسات والأجهزة، مع إمكانية الإنهاء عن بُعد.
- `grades` / `modules` / `lectures` — الصف ← الترم/الوحدة ← المحاضرة.
- `lecture_progress` — متابعة الإنجاز الفعلية.
- `activation_codes` — مخزّنة كـ `sha256` مع آخر 4 أحرف فقط للعرض، حالة (active/used/revoked)، وصلاحية.
- `subscriptions` — مصدر الاشتراك (كود/يدوي)، تاريخ البداية والنهاية.
- `exams` / `questions` / `exam_attempts` — الاختبارات والتصحيح الآلي والمحاولات.
- `assignments` / `submissions` — الواجبات والتقييم اليدوي.
- `notifications` / `announcements` — الإشعارات وإعلانات الصفحة الرئيسية.
- `activity_log` — سجل العمليات الإدارية والحساسة.

طبّق التغييرات بـ `npx drizzle-kit push`.

## 5. الأمان

- تجزئة كلمات المرور بـ `scrypt` مع مقارنة آمنة (`timingSafeEqual`).
- الجلسات تُخزَّن كـ hash للتوكن، والكوكي `httpOnly` + `sameSite=lax` + `secure` في الإنتاج.
- كل عملية حساسة (إنشاء محاضرة، إصدار أكواد، تفعيل، تغيير كلمة مرور) تتحقق من الدور **على الخادم**
  عبر `requireUser('teacher'|'student')` — لا عبر إخفاء الأزرار.
- أكواد التفعيل تُخزَّن مجزّأة، تُستخدم مرة واحدة، ولها صلاحية، مع قفل مؤقت بعد 5 محاولات فاشلة.
- إخفاء إجابات الأسئلة الصحيحة عن صفحة الأسئلة (تظهر فقط في المراجعة حسب إعداد المدرس).
- سجل عمليات لكل الإجراءات الحساسة.

## 6. المعمل الرياضي

- **رسم الدوال**: محرّك تعبيرات حقيقي (`src/lib/mathEval.ts`)، مجال قابل للتحكم، تكبير/تصغير، سحب
  للتحريك، وعرض نقاط تقاطع المحور السيني.
- **السبورة**: قلم، خط، مستطيل، دائرة، سهم، ممحاة، ألوان وسماكة، تراجع/إعادة، وحفظ كصورة PNG.
- **الآلة الحاسبة العلمية**: دوال مثلثية وأسّية وجذور ولوغاريتمات مع وضع درجة/راديان وسجل.
- **محرر المعادلات**: LaTeX مع معاينة فورية وقوالب جاهزة وزر نسخ.
- **المجسمات ثلاثية الأبعاد**: تدوير بالسحب، تغيير الأبعاد، وحساب الحجم والمساحة بقوانين صحيحة.

## 7. النشر

1. اربط المستودع بـ GitHub.
2. أنشئ المشروع على Vercel وحدّد `DATABASE_URL` (والمفاتيح الاختيارية) في Environment Variables.
3. شغّل `npx drizzle-kit push` مرة واحدة على قاعدة الإنتاج.
4. تأكد من استجابة `/api/health` بقيمة `{"ok": true, ...}`.

### خدمات خارجية تتطلب مفاتيح/اشتراكات

- **قاعدة بيانات PostgreSQL** (Supabase أو Neon أو أي مزوّد) — مطلوبة دائماً.
- **OpenAI API** — للمساعد الذكي فقط (اختياري).
- **Google OAuth** — لتسجيل الدخول عبر Google (اختياري).
- **تخزين الملفات/الفيديو** — روابط الفيديو والمذكرات تُخزَّن كروابط، ويمكن ربط Supabase Storage
  أو أي CDN لاحقاً دون تغيير بنية الجداول.
